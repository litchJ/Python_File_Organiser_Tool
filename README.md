# Python_File_Organiser_Tool
Python File organiser tool built using Tkinter GUI. The program will organise files into folders based on file extensions to automate pc clean up tasks.
Open the file in your IDE, Visual studio code was used to build this
Run the software 

When the software opens, you can find a folder or space full of different files and select it
confirm to organise the files
the program will automate the organisation process and file them for you with appropriate titles
